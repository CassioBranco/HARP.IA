# T5 — Post no Google Perfil de Empresa

**Pilar:** GBP
**Quem faz:** você, num perfil de empresa real que você controla
**Quanto dura:** 20 minutos

O critério é o resultado, não o mecanismo:

> **O post apareceu no perfil do Google?**

Se apareceu, o pilar funcionou — não importa se foi a API ou se você colou.
Se não apareceu, não funcionou — não importa quanto código existe.

---

## Passos (caminho B — fluxo assistido)

| # | o que fazer | o que tem que acontecer |
|---|---|---|
| 1 | Informar o link do perfil no onboarding | Valida de verdade. Aceitar texto qualquer reprova. |
| 2 | Abrir a tela do Google no painel | Mostra os posts do mês, não um campo vazio |
| 3 | Pedir os posts do mês pra IA | Vem um calendário, não um post avulso |
| 4 | Ler o texto gerado | Você postaria isso no perfil de um cliente pagante? |
| 5 | Clicar em copiar | Copia formatado e abre o perfil na tela de criar post |
| 6 | Colar e publicar no Google | Cola limpo, sem lixo de formatação |
| 7 | Marcar "publiquei" no painel | Entra no histórico com a data |
| 8 | Voltar no dia seguinte | O painel sabe qual é o próximo post e lembra você |
| 9 | Conferir o perfil no Google | **O post está lá, visível pra quem busca** |

---

## Se o acesso à API do Google sair

Os passos 5, 6 e 7 viram um só: clicar em publicar. Os outros continuam iguais.
O roteiro não muda de critério — muda de quantidade de cliques.
