Núcleo de design ANCOREO v2 (2026-07-01): **impresso naval vintage + editorial moderno**, construído do zero. Cássio rejeitou explicitamente reaproveitar a linguagem HARPIA (liquid-glass, aura, cards translúcidos) — foi feio recolorir; o núcleo precisa nascer do ANCOREO.

**Why:** ANCOREO = âncora/carta náutica. A primeira tentativa (retema do layout HARPIA em navy/vermelho) foi rejeitada pelo Cássio ("achei muito feio, não gostei que reutilizou os designs do harpia").

**How to apply:** Fonte de verdade = `docs/DESIGN-NUCLEO.md` no repo. Resumo: papel quente #F7F4ED (nunca branco frio), tinta navy #0A2239, vermelho sinal #D7263D escasso; Fraunces (display) + IBM Plex Mono (rótulos técnicos) + Inter (corpo); bordas 2px + sombras duras 5px 5px 0 (carimbo); selos circulares rotacionados, flâmulas clip-path, numerais vazados, marquee vermelho, borda escalopada, coordenadas mono. Landing pronta (escopo `.anc`); painel/onboarding/editor ainda pendentes de migração pra v2.
